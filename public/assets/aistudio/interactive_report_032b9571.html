Script Logic Flow

The procedural execution path of the V14.0 Sentinel Script.

1 Initialization & Persona Selection

Validates arguments. Sets PERSONA_NAME and corresponding SYSTEM_INSTRUCTION based on input (Kairo, Resonance, Nexus).

2 Payload Construction

Builds the JSON payload using jq, embedding the user query, activating the google_search tool, and injecting the selected Persona instructions.

3 Redundant Execution Loop

Iterates through KEYS_ARRAY. Executes curl POST request to the Gemini 2.5 Flash endpoint with a 30-second timeout.

for i in "${!KEYS_ARRAY[@]}"; do ... curl ...

4A Success: Output & Exit

If response is valid, extracts text via jq, formats output with Persona header, and exits with code 0.

4B Failure: Fallback & Error

If key fails, logs a snippet of the error to stderr. If loop completes without success, outputs "EXECUTION FAILURE" and exits with code 1.
